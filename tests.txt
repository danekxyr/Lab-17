Тест 1:
Исходные данные: массив {4, -2, 7, 4, 0}, n = 5
Ожидаемый результат: -2 0 4 4 7 (сохранены оба вхождения числа 4)
Фактический результат: -2 0 4 4 7
Статус: совпало

Трассировка переменных для Теста 1 (массив a = {4, -2, 7, 4, 0}, n = 5):
1. Начальное состояние: a = {4, -2, 7, 4, 0}.
2. Проход i = 0 (поиск минимума на индексах 0..4):
   - min_index = 0 (значение 4).
   - j = 1: a[1] = -2 < 4 -> min_index = 1.
   - j = 2..4: значений меньше -2 нет.
   - Обмен a[0] и a[1]: массив становится {-2, 4, 7, 4, 0}. Готовый префикс: [-2].
3. Проход i = 1 (поиск минимума на индексах 1..4):
   - min_index = 1 (значение 4).
   - j = 2: 7 < 4 (ложь); j = 3: 4 < 4 (ложь); j = 4: 0 < 4 -> min_index = 4.
   - Обмен a[1] и a[4]: массив становится {-2, 0, 7, 4, 4}. Готовый префикс: [-2, 0].
4. Проход i = 2 (поиск минимума на индексах 2..4):
   - min_index = 2 (значение 7).
   - j = 3: 4 < 7 -> min_index = 3; j = 4: 4 < 4 (ложь).
   - Обмен a[2] и a[3]: массив становится {-2, 0, 4, 7, 4}. Готовый префикс: [-2, 0, 4].
5. Проход i = 3 (поиск минимума на индексах 3..4):
   - min_index = 3 (значение 7).
   - j = 4: 4 < 7 -> min_index = 4.
   - Обмен a[3] и a[4]: массив становится {-2, 0, 4, 4, 7}. Готовый префикс: [-2, 0, 4, 4].
6. Завершение цикла (i = 4 < 4 ложно): последний элемент 7 автоматически на своём месте. Итоговый массив: {-2, 0, 4, 4, 7}.
