* **Тема:** Сортировка массива

## Назначение файлов проекта

* **`main.c`** — реализация алгоритма сортировки выбором по возрастанию `sort(int a[], int n)` с поиском минимального элемента в неотсортированной части массива и обменом после внутреннего цикла.
* **`self.c`** — реализация сортировки выбором по убыванию `sort_desc(int a[], int n)` и функции проверки упорядоченности `is_descending(const int a[], int n)`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов, включая пошаговую трассировку массива для первого опыта.

## Ограничения и правила

* Сортировка выполняется на месте (in-place) и изменяет исходный массив; повторяющиеся элементы сохраняются без потерь.
* В функции `is_descending` пустой массив (`n = 0`) и массив из одного элемента (`n = 1`) считаются упорядоченными (функция возвращает `1`).
* Равные соседние элементы допускаются (невозрастающий порядок).

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab17
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```
